Copyright 2015 The Vazirmatn Project Authors (https://github.com/rastikerdar/vazirmatn).
Distributed under the SIL Open Font License; see [OFL.txt](OFL.txt).

These are the existing Google Fonts variable WOFF2 subsets previously emitted by
the project's Next.js font loader: Arabic/Persian, Latin Extended, and Latin.
They support normal weights 100–900. The CSS retains their original Unicode ranges.
Serving the files here removes the development/build-time Google Fonts dependency.
