# 01 — Project Scope

## 1.1 تعریف
Gold System یک سامانه آنلاین برای مدیریت و اجرای معاملات طلای آب‌شده است که برای یک طلافروشی واحد طراحی می‌شود.

## 1.2 در Scope
### مشتری
- ثبت‌نام آنلاین
- بارگذاری اطلاعات و مدارک
- احراز هویت
- تأیید یا رد عضویت
- تعیین گروه مشتری
- مشاهده حساب و اعتبار
- ثبت سفارش
- مشاهده پیش‌فاکتور
- دانلود پیش‌فاکتور
- مشاهده وضعیت سفارش و معامله
- مشاهده پرداخت و تسویه

### قیمت
- دریافت قیمت از API خارجی
- ذخیره Price Snapshot
- کنترل صحت و تازگی قیمت
- Adjustment درصدی
- Adjustment مبلغ ثابت
- افزایش یا کاهش قیمت
- Pricing Rules
- محاسبه قیمت نهایی

### معامله
- Order
- Order Item
- Quotation
- Assignment
- Manual Review
- Approval / Rejection / Revision
- Trade
- Settlement

### خرید
- تعریف بالادستی
- ثبت خرید
- خرید ریالی
- خرید طلایی
- ثبت اثر مالی/طلایی
- مدیریت حساب بالادستی

### مالی
- Customer Account
- Supplier Account
- Financial Ledger
- Gold Ledger
- Payment
- Receivable / Payable
- Settlement
- Expense

### کنترل
- Role/Permission
- Notification
- Audit Log
- گزارش‌ها

## 1.3 خارج از Scope فعلی
- Multi-store
- انبارداری سنتی قطعات طلا
- مدیریت کالاهای فروشگاهی مانند انگشتر و گردنبند
- جایگزینی کامل نرم‌افزار حسابداری حرفه‌ای
- اتصال اجباری به همه بالادستی‌ها در نسخه اول
- اتوماسیون کامل تأیید معامله بدون انسان

## 1.4 فرضیات
- یک فروشگاه فعال وجود دارد.
- قیمت از یک یا چند Provider خارجی قابل دریافت است.
- معامله اصلی طلای آب‌شده است.
- نوع مشتری در قیمت‌گذاری/شرایط می‌تواند مؤثر باشد.
- تأیید دستی معامله یک کنترل اجباری است مگر Business Rule مشخصاً تغییر کند.

## 1.5 اصل مرزی
سیستم باید بین `Order`, `Quotation`, `Trade`, `Payment`, `Settlement`, `FinancialTransaction` و `GoldTransaction` تفکیک روشن داشته باشد.
