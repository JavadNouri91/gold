# 08 — Workflows

## 8.1 Customer Onboarding
```text
Registration
  -> Documents Submitted
  -> KYC Pending
  -> Under Review
  -> Approved / Rejected
  -> Customer Type Assigned
  -> Account Activated
```

## 8.2 Customer Trade
```text
View Live Price
  -> Pricing
  -> Order Created
  -> Quotation Generated
  -> Assignment
  -> Manual Review
  -> Approved / Rejected / Revision
  -> Trade Confirmed
  -> Payment/Settlement
  -> Completed
```

## 8.3 Revision
```text
Under Review
  -> Revision Requested
  -> Customer/Operator Updates
  -> New Quotation Version
  -> Review Again
```

## 8.4 Purchase
```text
Provider Price
  -> Purchase Draft
  -> Purchase Confirmed
  -> Rial/Gold Settlement
  -> Supplier Ledger
  -> Reconciliation
```

## 8.5 Payment
```text
Payment Intent/Entry
  -> Validation
  -> Allocation
  -> Ledger Posting
  -> Settlement Status Update
```

## 8.6 Price Feed
```text
External API
  -> Fetch
  -> Validate
  -> Normalize
  -> Store Snapshot
  -> Mark Current
  -> Pricing Engine
```
